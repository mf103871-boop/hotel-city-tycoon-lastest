# تحقق من النشر — 5 ثوانٍ

النسخة الحيّة حالياً **أقدم من الشيفرة**. الدليل ثلاثي:

| ما ظهر عندك | ما يعنيه |
|---|---|
| `60 loaded, 20 missing` | العشرون هي أشرطة المشي بالضبط، وُلّدت بعد ذلك النشر |
| الرقم مطابق للفحص السابق | البناء الحيّ لم يتغيّر بين الفحصين |
| الشارة لا تظهر مع `?debug=1` | دعم `?debug=1` أُضيف في v1.1 |

**هذه الحزمة تشحن 263/263 أصلاً و20/20 شريط مشي.**

## لن نخمّن مرة أخرى

من الآن، اللعبة تُعلن هويتها. **أول سطر في وحدة التحكم قبل أي شيء آخر:**

```
[hotel-city-tycoon] build 0.1.0+20260829T08, 263 assets declared
```

وبعد تحميل الأصول، أحد سطرين:

```
[assets] complete: all 263 declared textures available
```

أو:

```
[assets] 20 of 263 declared textures missing — if this is a deployment,
         it may be older than the asset set. First few: guest.vip.walk, ...
```

**السطر الثاني يسمّي المشكلة بنفسه** بدل أن تبدو عطلاً في الرسم.

## وتشخيص لا يحتاج الواجهة أن تعمل

الشارة داخل React — فبناء يفشل في الرسم يُخفي الأداة الوحيدة لمعرفة السبب.
لذلك أضفت دالة تُعرَّف **قبل** أن يبدأ أي شيء:

افتح وحدة التحكم واكتب:

```js
await window.hct.report()
```

تطبع وتنسخ للحافظة:

```
build                  0.1.0+20260829T08
assets declared        263
canvas                 present
walk sheet             200 12KB
room art               200 34KB
manifest               200 41KB
manifest entries       263 served vs 263 expected
```

**السطر الأخير هو الحكم.** إن اختلف الرقمان تظهر:

```
VERDICT   the served assets do not match this build — redeploy
```

وشريط المشي هو أحدّ اختبار للطزاجة: موجود فقط في البناءات التي تلي عمل الحركة.
إن أعاد 404، فالنسخة قديمة قطعاً.

## المطلوب

1. **انشر من `hotel-city-tycoon-v1.1.zip`** — تأكد أن `npm run build` يعمل وأن
   محتوى `dist/` هو ما يُرفع
2. افتح الرابط، ثم وحدة التحكم
3. أرسل لي ناتج `await window.hct.report()`
4. وسطور `[hotel-city-tycoon]` و `[assets]` كما هي

إن أظهر التقرير `263 served vs 263 expected` **والكبسولات ما زالت موجودة**،
فذلك عطل حقيقي جديد وسأطارده. وإن أظهر رقمين مختلفين، فالمشكلة في خط النشر لا
في اللعبة.

## ملاحظة على خط النشر

`public/assets/` يُنسخ إلى `dist/assets/` بواسطة Vite تلقائياً. إن كانت منصة
النشر تبني بنفسها، تأكد أنها تشغّل `npm run build` لا مجرد رفع الملفات — وأن
`dist/` كامل المجلد هو ما يُقدَّم.

للتأكد يدوياً بعد البناء:

```bash
npm run build
ls dist/assets/characters/*_walk.png | wc -l    # يجب أن يطبع 20
```

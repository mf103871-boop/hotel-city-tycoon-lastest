# سبب الكبسولات

**البصمة أدّت عملها.** بناؤك حديث (`0.1.0+20260829T0829`) و `manifest.json`
يقدّم 263 مدخلاً. فالنشر سليم، والمشكلة عندي.

---

## السطر الواحد

```
.gitignore
─────────────
public/assets/     ← هذا
```

كتبته في **P1** حين كان `public/assets/` مجلد مُخرَجات مبنية. ثم في **P3c.1**
نقلت الفن كله إليه ليقدّمه Vite — **ونسيت السطر.**

النتيجة: أي خط نشر يمرّ عبر git يُسقط الفن كله بصمت. والغرف نجت **بالمصادفة**
لأنها كانت مودعة قبل أن تبدأ القاعدة تُطبَّق، وأشرطة المشي وُلّدت بعدها فلم
تودَع قط.

ولهذا كانت مشاهدتك دقيقة تماماً:

| ما فحصته | النتيجة | السبب |
|---|---|---|
| `lobby_base.png` | صورة 256×96 | مودعة قبل القاعدة |
| `guest_tourist_walk.png` | **صفحة اللعبة** | غير موجودة، فالخادم يردّ بـindex.html |

وثلاث كبسولات مقابل شخصية واحدة مرسومة: الثلاث من نوع نفدت أشرطته، والرابعة من
نوع ما زال إطاره الثابت يُقرأ.

## الإصلاح، وثلاثة حراس

**السطر حُذف**، ومكانه شرح يمنع إعادته.

وأهم من الحذف أن **البناء صار يرفض النشر الناقص**. `npm run build` يقارن ما في
`dist/` بما يعلنه المانيفست. جرّبته بمحاكاة نشرتك بالضبط:

```
✗ assets shipped    243 /   263
✗ 20 of 263 declared assets are not in dist/
  (first: characters/guest_business_walk.png, characters/guest_celebrity_walk.png, ...)
```

**لو كان هذا موجوداً قبل ثلاثة أيام لتوقّف البناء بدل أن يشحن صامتاً**، ولوفّر
علينا جولتَي فحص.

ومعه حارسان بلا متصفح: أن `.gitignore` لا يستثني شيئاً تحت `public`، وأن كل
أصل يعلنه المانيفست موجود في شجرة المصدر.

## عن `fps 1`

قراءة مقلقة، لكنني أرجّح بيئة الفحص الآلي — أدوات لقطات الشاشة تخنق مُركِّب
المتصفح، و5 غرف لا تُتعب أي جهاز.

**لكنني قِست بدل أن أفترض**، فوجدت مشكلة قابلية توسّع حقيقية: المشهد يُعاد
بناؤه عشر مرات في الثانية، وكل إعادة بناء كانت تبحث عن تعريف كل غرفة وكل
شخصية **بمسح خطّي** على الأنواع الـ23. غير محسوس عند خمس غرف، وآلاف المقارنات
الضائعة في الثانية عند ثمانين. ووثيقة P0 تمنع هذا في المسار الساخن صراحةً.

صار البحث بفهرس. والقياس بعد الإصلاح، بفندق من **74 غرفة و35 نزيلاً**:

```
600 إعادة بناء (دقيقة كاملة عند 10Hz): 48ms — 0.08ms لكل واحدة
```

**هذا يستبعد المنطق كسبب لـ`fps 1` نهائياً.** إن بقيت القراءة منخفضة على جهاز
حقيقي، فالسبب في طبقة Pixi أو الجهاز، وسأطارده هناك.

## المطلوب

1. انشر من هذه الحزمة. **إن كان خط النشر يمرّ عبر git، تأكد أن
   `public/assets/` صار مُودَعاً** — القاعدة كانت تُسقطه:
   ```bash
   git add -f public/assets && git status --short | head
   ```
2. بعد `npm run build` يجب أن ترى:
   ```
   ✓ assets shipped    263 /   263
   ```
   إن لم ترها، **البناء سيفشل ويسمّي الملفات الناقصة.**
3. افتح الرابط. المتوقّع في وحدة التحكم:
   ```
   [assets] complete: all 263 declared textures available
   ```
4. **وأحتاج قراءة إطارات من متصفح حقيقي** — هاتفك أو حاسوبك، لا أداة آلية.
   افتح `?debug=1` وانظر إلى السطر `fps` أثناء السحب لا أثناء السكون.

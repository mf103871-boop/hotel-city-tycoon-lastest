## 132 ملفاً مشتقّاً مجاناً

حوّلت المولّدات لتعمل على **فنّك** بدل رسومي:

```bash
npm run gen:art:derive
```

يقرأ كل `<room>_base.png` ويُنتج منه أربعة أنواع:

| النوع | كيف |
|---|---|
| `_night` | غسلة باردة مع إبقاء مصادر الضوء دافئة |
| `_dirty` | إزالة تشبّع نحو المغرة وتعتيم، أثقل قرب الأرضية |
| `_pest` | **طبقة شفافة فقط**، تُركَّب فوق الأساسية وقت التشغيل |
| `_thumb` | 96×96 لقائمة البناء |

92 نوعاً للغرف و40 للشخصيات. **132 ملفاً لم يرسمها أحد**، وكلها تتبع فنّك.
وحين تستبدل صورة أساسية، أعد تشغيل الأمر فتتبعها أنواعها.

المشتقّات تعمل جيداً على لوحتك: الليل أزرق بارد والمصابيح تبقى دافئة،
والاتساخ زيتوني باهت، والحشرات مقروءة.

## قرار اتخذته: أعدت بناء لوحة الواجهة

**لوحتك نهارية دافئة، وواجهتي كانت ليلية باردة.** نعناعي `#b8d8d0` مقابل كحلي
`#081220` — تصادم حرارة في كل موضع يلتقيان فيه، وخلفية الكانفاس كانت ستبدو
سوداء خلف غرف ساطعة.

فقِست ألوان فنّك بدل أن أخمّن:

```
#b8d8d0  الجدران النعناعية
#f8f0d8  الكريمي
#f07858  الأبواب المرجانية
#e08030  الخشب
```

وأعدت بناء الواجهة منها: **فحم دافئ `#1a1210`** للإطار — يُقرأ كليل خارج فندق
مضاء — والمرجاني للأزرار الرئيسية، والخشبي للأرقام والعملة.

بدّلت معها: خلفية المُصيِّر، والشبكة، والأشكال البديلة، وفقاعات الرغبات، وحلقة
الإنقاذ، والأيقونات الأربع، والأيقونة المفضّلة، ولون المانيفست والوسم.

**الأسماء القديمة أُبقيت كأسماء مستعارة** فلا شيء ينكسر، والتبديل قابل للتراجع
بتعديل `src/index.css` وحده.

## ما زال ناقصاً من المواصفة — وليس عاجلاً

| البند | العدد | الحالة |
|---|---|---|
| `_walk` للشخصيات (6 إطارات، 288×72) | 20 | البديل حالياً إطار ثابت |
| ديكور ما بعد المستوى 5 | 39 | البديل الرسم البرمجي |
| `@2x` لكل شيء | — | اختيارية |

اللعبة تعمل كاملة بدونها. `_walk` هي الوحيدة التي ستُحدث فرقاً محسوساً — الفندق
سيبدو حياً فعلاً حين تتحرك السيقان.

## وما زال الأهم

**سبع مراحل لم تُتحقَّق على جهاز، والآن ثامنة معها فن جديد بالكامل ولوحة واجهة
جديدة.**

```bash
npm install
npx playwright install chromium
npm run verify
npm run test:e2e
```

سيناريو `the room art actually loads` هو الذي يهمّني أكثر من غيره هذه المرة.

### لماذا الصف الأخير معلّق

بيئتي بلا شبكة، فلا `npm install` ولا Zod ولا tsc ولا vitest. لذلك بنيت
`validate:data:refs` **بلا أي اعتماديات** حتى أستطيع تشغيله فعلياً — وشغّلته.
أما الأربعة الباقية فتحتاج `node_modules`، وهي مهمتك على Replit.

## ما أمسكه المُدقّق فعلياً

في أول تشغيل رفض البناء بخطأ حقيقي:

```
✗ decor.json: room "lobby" needs 300 decor points
  but only 160 is reachable at L1 with 8 slots
```

غرفة الاستقبال كانت تطلب عدّاد ديكور مستحيل الملء في المستوى 1 — أي أن أول
غرفة يراها اللاعب لن تصل للأخضر أبداً في بداية اللعبة. هذا هو نمط الإحباط
الذي أغرق اللعبة الأصلية. أُصلح بخفض الهدف إلى 150، وأُحكمت القاعدة:

- غرف البداية: يجب أن تكون قابلة للملء **فوراً** عند مستوى فتحها
- الغرف اللاحقة: يُسمح لها بمهلة 5 مستويات، ثم تصبح إلزامية

## قرارات توازن اتُّخذت في هذه المرحلة

كل الأرقام موسومة `provisional-awaiting-P2-balance-sim` — تُضبط نهائياً بعد
بناء المحاكي في P2. أهم انحرافين متعمدين عن اللعبة الأصلية:

**منحنى الخبرة.** الأصلية طلبت 6,280,000 نقطة عند المستوى 52. منحنانا
`round(120 × level^2.35)` يصل إلى **1,810,660 عند المستوى 60** — أي ثلث
المطلوب مع مستويات أكثر. هذه أول وأهم معالجة للخطأ الذي قتل اللعبة الأصلية.

**تكلفة الوردية.** الأصلية قفزت من 1,781 عملة (24 ساعة) إلى 14,145 (48 ساعة)
— جدار مالي بلا مبرر. عندنا الصيغة خطية: `base × (1 + 0.08 × (level−1))`.

## مطابقة الغرف الـ23

استخدمت أنواع غرفك الـ23 التي لديك فنّها بالفعل، وطبّقت عليها بنية Hotel City:

- **نزلاء (9):** economy → standard → double → family → deluxe → executive → honeymoon → luxurySuite → presidential
- **تجارية (8):** cafe, gym, restaurant, bar, arcade, cinema, spa, pool
- **وظيفية (6):** lobby (مدخل), housekeeping (تنظيف 14 غرفة), laundry (+6 غرف، ‑15% اتساخ), staffRoom (‑10% أجور), maintenance (‑50% حرائق), business (+12% وصول نزلاء)

`business` يؤدي دور "مدير الحجوزات" في اللعبة الأصلية: يرفع معدل وصول النزلاء.

## للتشغيل عندك

```bash
npm install
npm run validate:data
npm run typecheck && npm run lint && npm run test:logic && npm run build
npm run dev
```

الشاشة تعرض تقرير بيانات حياً — كل رقم فيها مقروء من `data/*.json`، ولا رقم
واحد مكتوب في الكود. تُحذف هذه الشاشة في P3 عند وصول الكانفاس.

## اقتراح لاختبار الحدود

جرّب إضافة `import React from 'react'` داخل أي ملف في `src/core` ثم شغّل
`npm run lint`. يجب أن يفشل برسالة صريحة. إن لم يفشل فالقاعدة معطوبة وأريد
أن أعرف.

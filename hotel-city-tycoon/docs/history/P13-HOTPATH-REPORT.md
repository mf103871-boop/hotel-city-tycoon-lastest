# المسار الساخن — أول قياس لميزانية المحاكاة

**سؤالان لم يُطرحا، وكلاهما في المسار الساخن.**

---

## 1. ماذا يحدث حين يعود تبويب مخنوق؟

المحرك يعوّض كل خطوة فائتة **دفعة واحدة** ما دام الغياب دون ستين ثانية. وهذا
مصدر تجمّد كلاسيكي: تعود إلى التبويب فتجد الشاشة تتوقف لحظة.

قِست أسوأ حالة على فندق من 64 غرفة:

```
  غياب 0.1s =   1 خطوة  →  0.1 ms
  غياب   5s =  50 خطوة  →  0.6 ms
  غياب  30s = 300 خطوة  →  4.6 ms
  غياب  59s = 590 خطوة  →  9.0 ms   ← أسوأ حالة، تحت إطار واحد
```

**لا مشكلة.** والقياس هو ما أثبت ذلك بدل الحدس — وكان يمكن أن يكون العكس تماماً
بنفس الاحتمال.

وفحص ثانٍ يحرس **الشكل لا الرقم**: أن التكلفة تنمو خطياً مع الزمن لا بمربّعه.
النمو التربيعي يعني أن أسوأ حالة بلا سقف، مهما كانت الأرقام اليوم مريحة.

## 2. أول قياس لميزانية المحاكاة في الوثيقة

الوثيقة خصّصت للمحاكاة **2 مللي ثانية** من إطار الـ16.7، وكتبت ذلك في يومها
الأول. **ولم تُقَس مرة واحدة عبر ثلاث عشرة مرحلة.**

```
  خطوة واحدة على فندق من 60 غرفة:  0.013 ms
  الميزانية:                        2.000 ms
  الهامش:                           150 ضعفاً
```

هذا يُغلق نصف ميزانية الإطار. **النصف الآخر — تكلفة الرسم — ما زال يحتاج
متصفحاً.**

## 3. وهل تحتمل الأرقام سنوات؟

العملات أرقام JavaScript عادية. فوق `9×10¹⁵` تتوقف عن الدقة، **واللاعب يبدأ
يخسر مالاً للتقريب بلا أن يعرف لماذا.**

عشر سنوات بمعدل سخيّ جداً تبقى **820 ضعفاً تحت الحدّ**. آمن بهامش واسع.

وسقف الغياب يعمل: سنة كاملة تدفع ما تدفعه أربع عشرة ساعة.

## عيب صغير كشفه سطر تشخيصي

طبع أحد قياساتي `capped at undefined` — كنت أقرأ حقلاً باسم غير موجود. الغطاء
يعمل بـ`maxOfflineHours`، والخطأ في سطري وحده.

**لكن الشكل يستحق حراسة:** حقل غير موجود يُقرأ `undefined` بصمت فيصير `NaN` أو
يسقط إلى قيمة احتياطية، ولا يشتكي أحد.

```
✓ no code reads a data field that does not exist
```

يجمع كل مفاتيح `economy.json` ويقارنها بكل ما تقرأه الشيفرة منها.

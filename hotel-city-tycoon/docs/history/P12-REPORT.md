# P12 — حين يفشل شيء أثناء اللعب

**بُعد لم يُفحص عبر اثنتي عشرة مرحلة.** قِست اللعبة تحت الظروف الجيدة فقط، ولم
أسأل قط ماذا يحدث حين يفشل شيء وهي تعمل.

وجدت ثلاثة أعطال، **وهي أخطر ما وجدته في المشروع كله** — لأن الحفظ المحلي هو
النسخة الوحيدة من فندق اللاعب، وكلها كانت صامتة.

---

## 1. خطأ رسم واحد يُفرغ الشاشة

**لا حدود أخطاء إطلاقاً.** استثناء واحد في أي مكوّن يُسقط شجرة React كلها،
واللاعب يرى **صفحة فارغة مكان فندقه** — لا يميّزها عن فقدان كل شيء.

بينما الحفظ سليم تماماً على القرص.

`ErrorBoundary` الآن يمسك ذلك، **وأهم ما تفعله شاشته أن تقول إن الحفظ بخير**،
وتعرض تنزيل الفندق **قبل** زر إعادة التحميل. من يستطيع تصدير فندقه لم يخسر
شيئاً مهما حدث بعدها. وترتيب الزرين ليس تفصيلاً: "إعادة تحميل" هو الزر الذي
يبدو كالاستسلام.

## 2. فشل الحفظ يُبتلع صامتاً

```js
const persist = (state) => { void saves.save(state, now()); };
```

`void` بلا `catch`. متصفح امتلأ تخزينه — أو نافذة خاصة حصتها صفر — **يتوقف عن
الحفظ واللاعب يواصل ساعات ثم يكتشف في زيارته التالية أن كل شيء ذهب.**

الآن `save()` تُعيد نتيجة بدل أن ترمي، وتميّز **امتلاء التخزين** تحديداً لأنه
الفشل الذي يصيب لاعباً حقيقياً والوحيد الذي يستطيع فعل شيء حياله. والمحرك يعدّ
الإخفاقات المتتالية، وبعد ثلاثة يظهر تحذير أحمر بزر تصدير.

**واللعبة تواصل العمل** — فقدان القدرة على التسجيل يجب ألا يوقف اللعب، فاللاعب
يحتاج فرصة لإنقاذ ما لديه.

## 3. النافذة الخاصة تُسقط الإقلاع

كشفه الفحص أثناء كتابته: `load()` كانت **ترمي** حين يكون التخزين غير متاح، بدل
أن تُبلغ. أي أن نافذة خاصة تُسقط الإقلاع **قبل أن تُرسم اللعبة أصلاً**.

صارت نتيجة `unavailable`، واللعبة تبدأ وتحذّر فوراً بدل انتظار ثلاث محاولات
حفظ فاشلة صامتة.

## الفحوصات

خمسة عشر فحصاً جديداً تحاكي الفشل بدل افتراض النجاح:

```
✓ a full browser is reported as full, not swallowed
✓ a save that cannot be written never throws at the caller
✓ a persist that throws is treated as a failure, not a crash
✓ one good save clears the count
✓ the game keeps running when it cannot save
✓ the crash screen offers the save before anything else
✓ the crash screen says the save is unharmed
✓ a 5,000-entry save is 39KB
```

فحص `the crash screen offers the save before anything else` يقارن موضع الزرين
في المصدر فعلياً — **ترتيبهما قرار تصميم يستحق حارساً**، لا مجرد ترتيب سطور.

```
run 29  runtime 24  render 21  regressions 21  assets 18  panels 23
characters 19  feedback 25  objectives 23  amenities 14  staff 11
upgrades 17  accessibility 13  resilience 15 ← جديدة  data-coverage 15  shipping 21
                                                                 ─────
                                                                  309
e2e: 24 سيناريو (+2: انهيار الرسم، والتخزين غير المتاح)
```

---

## ما يحتاج جهازاً

**افتح اللعبة في نافذة تصفّح خاص.** يجب أن تعمل، ويجب أن يظهر التحذير الأحمر
بأن التقدّم لا يُحفظ — لا شاشة بيضاء ولا صمت.

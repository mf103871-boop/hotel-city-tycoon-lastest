# Hotel City Tycoon — حالة المشروع

الوثيقة الوحيدة التي تصف أين المشروع. التقارير القديمة (49 ملفًا) في
`docs/history/`، وتقارير المراحل الجديدة في `docs/`.

## ما هو

لعبة إدارة فندق ثنائية الأبعاد للهاتف. **الهدف المعتمد: نسخة مطابقة لميكانيك
وأرقام Playfish Hotel City (2010)** بفن وواجهة وبنية جديدة بالكامل.

المرجعان الملزمان قبل أي تعديل:

1. `docs/AUDIT-AND-PARITY-REPORT.md` — خريطة الفروق نظامًا نظامًا بين البناء
   الحالي والأصل، والمراحل المتفق عليها.
2. وثيقة P0 المعمارية — **غير موجودة في المستودع بعد؛ يجب إضافتها إلى `docs/`.**

## هل تعمل؟

**بلا متصفح: نعم، ومُثبَت.** 628 فحصًا آليًا عبر 28 وحدة تغطي المحاكاة والحفظ
والتوازن والأصول والواجهة المنطقية، وكلها تعمل على checkout بارد بلا حزم.

**داخل متصفح: غير محسوم — بقرار المالك لا يُسجَّل PASS بصري إلا بعد فتح اللعبة في بيئة Chromium سليمة.** ما تحقق حتى الآن: التحقق البرمجي كامل، والفحص البصري الثابت للأصول ناجح (المالك عاين spa_base/night/thumb وأيقونات الحوادث الثلاث مباشرة وأكد قراءتها، وتأكد أن RoomView يرسم القوام الحقيقية والدائرة بديل فقط، وأن PhoneSheet وClimateBanner يعرضان الملفات الفعلية). 41 سيناريو Playwright مكتوبة ولم تُشغَّل قط — على Replit يفشل إطلاق Chromium لغياب مكتبات النظام (libglib-2.0 وأخواتها). الحل: إضافة حزم النظام إلى replit.nix (pkgs.glib، pkgs.nss، pkgs.atk، pkgs.at-spi2-atk، pkgs.gtk3، pkgs.alsa-lib، pkgs.libdrm، pkgs.mesa) ثم npx playwright install chromium، أو تشغيلها على جهاز يملك تبعيات Playwright.
**هذه أكبر فجوة تحقق متبقية.** على Replit:

```bash
npx playwright install chromium && npm run test:e2e
```

## البنية

```
data/          16 ملف توازن — مصدر الحقيقة، لا رقم واحد في الكود
src/core/      المحاكاة: نقية، حتمية، بلا Pixi ولا React ولا DOM ولا ساعة
src/bridge/    الجسر: المحرك، المتجر، الانتقاءات، الشخصيات، الإشعارات
src/render/    Pixi v8: كاميرا، قص، تجميع، إيماءات، شخصيات متحركة
src/ui/        React: لوحات، أوراق، إشعارات، إعدادات، تفضيلات الواجهة
src/save/      IndexedDB + ترحيلات + تصدير/استيراد
src/audio/     WebAudio، مدير واحد، بلا اعتمادية
tools/         مولّدات فن وترجمة، مُدقّقات، محاكيا توازن، مجموعات الفحص
docs/          تقارير المراحل + خريطة الفروق؛ docs/history للأرشيف
```

قاعدتان يفرضهما ESLint كأخطاء: النواة لا تستورد مُصيِّرًا ولا إطار عمل ولا
تقرأ ساعة؛ والواجهة لا تصل إلى النواة إلا عبر الجسر.

## فجوات معروفة ومسجَّلة

1. **اختبارات المتصفح لم تُشغَّل** — الأمر أعلاه؛ كل عطل شُحن سابقًا كان في
   أسلاك الواجهة.
2. **لا lockfile.** على Replit: `npm install --package-lock-only` ثم commit
   لملف `package-lock.json` (أو pnpm-lock.yaml إن اعتُمد pnpm — واحد فقط).
3. **وثيقة P0 المعمارية ليست في المستودع** — تُضاف إلى `docs/`.
4. **الانحراف أُغلق فنيًا في 5أ**: الديسكو رُسم ديسكو حقيقيًا (أرضية رقص
   متوهجة وكرة مرايا ونيون) — المعرّف الداخلي وحده يبقى `spa` بقرار 17أ
   الموقّع لسلامة الحفظات ومفاتيح الأصول، وهو غير مرئي للاعب.
5. **قياس الزمن ثنائي المنوال**: نفس العملية تقيس 14ms أو 62ms حسب وقوع GC.
   كل بوابة زمنية تحكم على وسيط 9 عيّنات (`tools/selftest/measure.ts`)؛ أي
   فحص زمني جديد يجب أن يستعمل نفس المُقدِّر لا `performance.now()` مباشرة.
6. **محاكيا التوازن لاعبان آليان مختلفان**: horizon يزيّن ويبني مرافق فيبلغ
   3 نجوم، وeconomy أكثر تحفظًا فيبقى عند 2. لا يصل أيهما إلى 4 نجوم لأن
   روبوتيهما لا يشتريان ديكورًا كافيًا — سلوك أداة لا حكم على اللعبة، ويُعاد
   النظر فيه عند معايرة مرحلة الأرقام.

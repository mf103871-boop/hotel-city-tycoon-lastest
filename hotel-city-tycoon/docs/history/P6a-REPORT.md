# P6a — تقرير التسليم

**المرحلة:** P6a — طبقة التحقق، الميزانيات، والتثبيت
**المخرج:** `hotel-city-tycoon-P6a.zip`

---

## الفجوة البنيوية التي أغلقتها

**كل عطل شحنته في هذا المشروع كان في المكان نفسه:** الأسلاك بين مكوّن واجهة
سليم ومنطق سليم.

- الفن مولَّد ومُتحقَّق منه و**لم يُحمَّل قط**
- مخزن الأحداث يُملأ و**لا أحد يقرأه**
- استيراد حزمة مشوّه أوقف تصريف طبقة العرض **إصدارين كاملين**
- التصدير والاستيراد موجودان **بلا واجهة تصل إليهما**

لا شيء من هذا كان قابلاً للالتقاط بالفحوص الـ189، لأن كله يحتاج متصفحاً.
`tests/e2e/` كان فارغاً منذ P0.

## 15 سيناريو متصفح

الآن ليس فارغاً. والفحص الذي يحرسه هو الأهم في المرحلة:

```
✓ every shipped failure has a test that would have caught it
```

يحمل قائمة بثمانية أعطال **شُحنت فعلاً** ويتأكد أن لكل واحد اختبار متصفح:

| العطل الذي شُحن | الاختبار |
|---|---|
| الإقلاع يعلق على شاشة التحميل (StrictMode) | `boots past the loading screen` |
| الفن موجود ولا يُحمَّل | `the room art actually loads` |
| المُصيِّر لا يُبلغ عن نفسه | `a renderer initialises and says which one` |
| العدّاد يبدو متجمّداً | `the shift countdown ticks every second` |
| عدّاد الديكور غير قابل للوصول | `decorating moves the meter` |
| الحفظ لم يُختبر في متصفح قط | `the hotel survives a full reload` |
| RTL يقلب الكانفاس | `without flipping the canvas` |
| التصدير بلا واجهة | `a save can be exported` |

إن أضفت ميزة وكسرت واحدة، **يفشل البناء بدل أن يشحن صامتاً.**

وفحوص أخرى تحرس جودة المجموعة نفسها: أنها تبدأ من فندق نظيف (وإلا نجحت
الاختبارات أو فشلت حسب ترتيبها)، وأنها تشغّل ملف هاتف لا سطح مكتب فقط —
واللعبة مصمّمة للهاتف وحده.

## الميزانيات صارت تُفرَض

وثيقة P0 وضعت أرقاماً في اليوم الأول ولم يتحقق منها شيء منذها. **ميزانية لا
أحد يفرضها أمنية.**

`npm run check:budget` صار جزءاً من `npm run build`:

```
✓ initial art       127KB /  3072KB
✓ audio             118KB /   400KB
✓ all assets        769KB /  8192KB
```

كل ما يُقدَّم للمتصفح **0.77 ميجابايت**. وحين تبني، يُضاف فحص حزمة JS المضغوطة
مقابل 400 كيلوبايت.

## قابلة للتثبيت وتعمل بلا شبكة

مانيفست كامل، وأربع أيقونات مولّدة بنفس لوحة الألوان (منها **maskable** وإلا
حاصرها أندرويد في دائرة بيضاء)، وعامل خدمة باستراتيجيتين:

- **الأصول: من الذاكرة أولاً** — الفن لا يتغيّر تحت الاسم نفسه، فاللعبة تفتح
  فوراً وبلا شبكة إطلاقاً
- **قشرة التطبيق: من الشبكة أولاً** — تقديم `index.html` قديم بعد نشر جديد
  يترك اللاعب على بناء قد لا يفهم ملف حفظه

والتسجيل في الإنتاج فقط. عامل خدمة يخزّن حزمة تطوير يُخفي كل تعديل حتى يمسح
أحدهم التخزين يدوياً.

## 18 فحصاً جديداً لأشياء تفشل بصمت

الـPWA لا ترمي أخطاء. أيقونة بحجم خاطئ، حقل ينقص المانيفست، عامل خدمة يقدّم
قشرة قديمة — لا شيء منها يفشل بصوت، وكله يكتشفه مستخدم.

فالفحوص تقرأ رؤوس ملفات PNG بلا مُفكِّك وتقارن الأبعاد الفعلية بما يدّعيه
المانيفست، وتتأكد أن لون الخلفية فيه يطابق ورقة الأنماط (وإلا ومض لون مختلف
عند الإقلاع)، وأن ترتيب `fetch` و `caches.match` في عامل الخدمة صحيح.

## ما تشغّله أنت

```bash
npm install
npx playwright install chromium
npm run verify        # كل شيء بلا متصفح
npm run test:e2e      # 15 سيناريو، سطح مكتب وهاتف
npm run build         # يفشل إن تجاوزت الميزانية
```

**هذه أول مرة تصير فيها طبقة الواجهة قابلة للتحقق.** إن فشل شيء، الصق الناتج
كما هو — Playwright يحفظ لقطة شاشة وتتبّعاً لكل فشل.

وللتثبيت: افتح اللعبة على هاتفك من رابط الإنتاج، ويجب أن يعرض المتصفح
"إضافة إلى الشاشة الرئيسية". بعدها اقطع الإنترنت وافتحها — يجب أن تعمل.

# تكافؤ المحمّلين، وأرقام تتبع اللغة

**فحصت شيئاً كان يقوّض كل ما سبقه، ولم أنظر فيه قط.**

---

## 1. عندي محمّلا بيانات، ولا شيء يجبرهما على الاتفاق

```
tools/balance-sim/load-data.ts   ← تقرأه الفحوص الـ397
src/data/index.ts                ← تقرأه اللعبة
```

**إن انحرفا، فكل ما أثبتّه يخصّ لعبة أخرى.**

قِست: الملفات الستة عشر نفسها، والحقول الثمانية عشر نفسها. **متطابقان اليوم —
لكن بالمصادفة لا بالبناء.** ولا شيء كان يمنع انحرافهما غداً، والانحراف صامت
بطبيعته: الفحوص تظل خضراء وهي تختبر شيئاً آخر.

وهذا الشكل من الخلل وقع مرتين فعلاً — ملف بيانات أُضيف لأحد المحمّلين ونُسي في
الآخر.

**ثمانية فحوص الآن تجعل الاتفاق خاصية لا صدفة:**

```
✓ both loaders read every file in data/           16 ملفاً
✓ both produce the same set of fields             18 حقلاً
✓ every field the core declares is supplied by both
✓ a value read through the loader is the value in the file
✓ every schema is applied to exactly one file
```

الرابع أهمها: لا يكتفي بوجود الحقل بل يقارن **قيمته** بالملف. محمّل يربط
`rooms.json` بمفتاح خاطئ كان سينجح في كل ما سبقه.

## 2. الأرقام كانت تتبع الجهاز لا اللغة

أربعة عشر موضعاً في الواجهة تستعمل `toLocaleString()` عارية.

**من يختار العربية على جهاز عربي يرى أرقاماً هندية، ومن يختارها على جهاز
إنجليزي يرى غربية.** نفس اللعبة، نفس الشاشة، أرقام مختلفة — **وليس للّعبة رأي
في ذلك.**

`src/i18n/format.ts` يربطها باللغة المختارة. والأرقام غربية في اللغتين **عن
قصد**: الأرقام الهندية عربية صحيحة، لكن لعبة تايكون تُقرأ أرقاماً أكثر مما
تُقرأ نصاً، ونظام أرقام يتبدّل مع الجهاز أسوأ من نظام ثابت.

**ومعها إصلاح للقراءة:** الفندق المتأخر يحمل مئات الملايين، و`268,146,111` في
زرّ **طول يُرى لا قيمة تُقرأ**. صارت `268.1M`. والأرقام الصغيرة تُترك كما هي —
اختصار ما يعدّه اللاعب في رأسه خسارة لا مكسب.

### وعطل أحدثه إصلاحي

الاستبدال الآلي ترك `Sheet.tsx` — وهو المكوّن المشترك الذي يعرض **كل سعر في
اللعبة** — يطبع رقماً خاماً بلا فواصل. **أسوأ من العيب الذي كنت أصلحه.**

راجعتها بالعين فوجدته، وأصلحته، **وكتبت له فحصاً**:

```
✓ the shared price row knows the language
```

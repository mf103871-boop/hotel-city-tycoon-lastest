# HC-P0-S4 — تقرير خادم CI المشترك

**التاريخ:** 01-09-2026
**الحالة:** `IMPLEMENTED` — الاعتماد النهائي ينتظر تشغيل CI كاملًا
**المرحلة:** HC-P0
**الخطوة:** HC-P0-S4

## نتيجة خط الأساس السابق

إصلاح الهدية اليومية نجح في تشغيل CI السابق؛ الدليل المتاح هو مرور الاختبارات
1 و2 و3 و5، والتقاط ثلاث لقطات. بقيت نتيجة CI غير مكتملة بسبب عائق الخادم.

العائق الجديد المثبت هو أن الخادم كان يُعاد إقلاعه لكل اختبار، ثم يُقتل برمز
الخروج `143`. هذا السلوك كان يستهلك وقت التشغيل ويمنع اكتمال مجموعة الاختبارات
واللقطات.

## فرق التعديلات

1. **`playwright.config.ts`**
   - تغيّرت قيمة `reuseExistingServer` من `false` إلى `true` فقط.
   - لم تتغير أي إعدادات أخرى في الملف.

2. **`tools/baseline-shots.mjs`**
   - أصبح إطلاق Chromium يمرر دائمًا `--disable-dev-shm-usage`.
   - تُضاف أعلام `PLAYWRIGHT_EXTRA_ARGS` بعد تقسيمها على المسافات عند وجود
     المتغير.
   - رُفعت مهلة فتح الصفحة من `30_000` إلى `60_000`.
   - بقيت أسماء اللقطات ومحدداتها وترتيبها ومنطق إغلاق الهدية كما هي.

3. **`.github/workflows/e2e.yml`**
   - أصبحت قيمة `PLAYWRIGHT_EXTRA_ARGS`:
     `--enable-unsafe-swiftshader --use-gl=angle --use-angle=swiftshader`
   - أضيفت خطوة `start server` قبل `e2e tests` لتشغيل خادم واحد في الخلفية
     باستخدام `nohup`، والانتظار عبر `curl` مرة كل ثانية لمدة تصل إلى 120
     ثانية.
   - أضيف `hotel-city-tycoon/docs/ci-server.log` إلى artifacts.
   - بقيت بقية الخطوات والمسارات كما هي.

4. **هذا التقرير**
   - يوثق خط الأساس، عائق إعادة تشغيل الخادم، وتغييرات S4 ونتائج التحقق.

لم تُعدّل `src` أو `data` أو `package.json` أو `package-lock.json` أو أي توكيد
اختبار، ولم يُشغّل E2E محليًا.

## التحقق المحلي

| الأمر | رمز الخروج | النتيجة |
|---|---:|---|
| `npm run typecheck` | 0 | ناجح |
| `npm run lint` | 0 | ناجح مع 4 تحذيرات `console` معروفة |

لم يتم تشغيل متصفح أو E2E محليًا، التزامًا بالقيد البيئي. ما يزال إثبات الخادم
المشترك ونجاح مجموعة CI الكاملة بانتظار تشغيل workflow في GitHub ومراجعة
`ci-server.log` و`e2e-results`.

## الحالة والقرار

أصبحت HC-P0-S4 `IMPLEMENTED`. لا تُنقل إلى `VERIFIED` قبل تشغيل CI كاملًا
والتأكد من أن الخادم يبدأ مرة واحدة، وأن الاختبارات واللقطات تكتمل، وأن artifact

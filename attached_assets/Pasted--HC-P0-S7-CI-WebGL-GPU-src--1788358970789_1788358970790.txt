نفّذ HC-P0-S7: مسار CI حتمي بلا WebGL، ومسبار GPU منفصل، وقراءة كود إقلاع المحرك. ممنوع تعديل src أو data أو package.json أو package-lock.json أو playwright.config.ts أو أي توكيد اختبار. لا تشغّل E2E محليًا.

1) أعد كتابة /home/runner/workspace/.github/workflows/e2e.yml بهذا المحتوى حرفيًا كاملًا:

name: e2e
on:
  workflow_dispatch:
  push:
    branches: [main]
defaults:
  run:
    working-directory: hotel-city-tycoon
jobs:
  e2e:
    runs-on: ubuntu-24.04
    timeout-minutes: 60
    env:
      PLAYWRIGHT_FULL_CHROMIUM: "1"
      PLAYWRIGHT_NO_CAPTURE: "1"
      PLAYWRIGHT_EXTRA_ARGS: --disable-3d-apis
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 24
      - name: sanitize lockfile
        run: sed -i 's|http://package-firewall.replit.local/npm|https://registry.npmjs.org|g' package-lock.json
      - name: install deps
        run: |
          set -o pipefail
          mkdir -p docs
          npm install --no-audit --no-fund 2>&1 | tee docs/ci-npm.log
      - name: install browser
        run: |
          set -o pipefail
          npx playwright install --with-deps chromium 2>&1 | tee docs/ci-install.log
      - name: e2e tests
        run: |
          set -o pipefail
          npx playwright test --reporter=line 2>&1 | tee docs/ci-run.log
      - name: baseline shots
        if: always()
        timeout-minutes: 15
        run: |
          set -o pipefail
          node tools/baseline-shots.mjs 2>&1 | tee docs/ci-shots.log
      - name: upload results
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: e2e-results
          path: |
            hotel-city-tycoon/docs/ci-npm.log
            hotel-city-tycoon/docs/ci-install.log
            hotel-city-tycoon/docs/ci-run.log
            hotel-city-tycoon/docs/ci-shots.log
            hotel-city-tycoon/test-results/
            hotel-city-tycoon/docs/baseline-screens/
          if-no-files-found: warn
  gpu-probe:
    runs-on: ubuntu-24.04
    timeout-minutes: 15
    strategy:
      fail-fast: false
      matrix:
        include:
          - name: swiftshader
            flags: --enable-unsafe-swiftshader --ignore-gpu-blocklist
          - name: angle
            flags: --use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist
    env:
      PLAYWRIGHT_FULL_CHROMIUM: "1"
      PLAYWRIGHT_NO_CAPTURE: "1"
      PLAYWRIGHT_EXTRA_ARGS: ${{ matrix.flags }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 24
      - name: sanitize lockfile
        run: sed -i 's|http://package-firewall.replit.local/npm|https://registry.npmjs.org|g' package-lock.json
      - name: install deps
        run: npm install --no-audit --no-fund
      - name: install browser
        run: npx playwright install --with-deps chromium
      - name: renderer probe
        continue-on-error: true
        run: |
          mkdir -p docs
          npx playwright test --project=desktop -g "renderer initialises" --timeout=120000 --reporter=line 2>&1 | tee docs/probe-${{ matrix.name }}.log
      - name: upload probe
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: gpu-probe-${{ matrix.name }}
          path: |
            hotel-city-tycoon/docs/probe-${{ matrix.name }}.log
            hotel-city-tycoon/test-results/
          if-no-files-found: warn

2) قراءة فقط: ابحث في src عن موضع النص renderer starting وعن كود إقلاع محرك الرسم، واكتب في التقرير وصفًا دقيقًا مع أسماء الملفات وأرقام الأسطر: ما تسلسل المحاولات بين webgpu وwebgl، وماذا يحدث إن رمى الإقلاع استثناءً، وماذا يحدث إن لم يُرجع الإقلاع نتيجة أبدًا، وهل توجد مهلة أو مسار تعافٍ أو fallback إلى canvas 2D، وهل يوجد أي تكرار أو حلقة إعادة محاولة. لا تعدّل شيئًا.

3) تحقق: npm run typecheck ثم npm run lint داخل hotel-city-tycoon، ويجب أن يكون رمز الخروج 0 لكليهما.

4) أنشئ docs/HC-P0-S7-REPORT.md يوثّق: نتيجة تشغيل S6 وهي 82 منفذة و29 ناجح و50 فاشل و3 متخطى في 37.9 دقيقة ولقطتان من خمس؛ وأن شارة التصحيح ما زالت renderer starting وfps 0 مع Chrome الكامل، وأن أخطاء PixiJS shader تكررت، وأن التجمد المتقطع للصفحة مثبت من فشل سكربت اللقطات في إيجاد أزرار الشريط السفلي في سياقات جديدة؛ وقرار المالك بفصل المسارين: مسار CI حتمي بلا WebGL لقياس طبقة القوائم والمنطق، ومسبار GPU لاختبار المحرك وحده تحت تركيبتين. أضف قسم قراءة كود الإقلاع من البند 2.
